# 桌面图标台球 · Desktop Billiards (WinForms)

一个用 **WinForms / .NET 10** 实现的桌面图标台球原型。

启动后从当前显示器的桌面图标中**随机选 15 个**，把图标渲染成**圆形玻璃球**，按真实台球开局摆成等边三角形。不足 15 个时，用不同颜色的编号球补足。白球放在真实的**头点（head spot）**，球架顶点放在**脚点（foot spot）**。用桌面壁纸作为球台背景，把 15 个球全部打进 6 个袋口即可清台。

## 已实现

- 随机 15 个桌面图标 → 圆形球：圆形裁剪、玻璃渐变、彩色描边、高光
- 真实台球摆位：白球在头点，15 球在脚点摆成 5 行等边三角形，8 号在中心
- 不够 15 个图标时自动生成不同颜色的编号球补足；所有球直径一致
- 球体顶部显示 1-15 号白色号码牌
- WinForms 全屏无边框游戏层（不依赖 WPF）
- 6 个袋口、球-球碰撞、库边反弹、台呢摩擦、落袋判定
- 白球、球杆、按住蓄力、力度环
- 瞄准辅助线、幽灵球、目标球预测方向（F1 开关）
- 进球特效：
  - 球体缩小 + 旋转飞入袋口
  - 粒子爆发
  - 袋口冲击波/闪光
  - 屏幕轻微闪白/金色
- 连续进球：
  - 每进一个球 `combo + 1`
  - 一杆未进球后 `combo` 归零
  - 在**最后进球的袋口上方**显示 `连击 ×2 / ×3 ...` 的玻璃标签
  - 顶部 HUD 同步显示当前连击
- 计时、进球数（0/15）、出杆数、清台结算
- `R` 重开会重新随机抽 15 个图标并重新摆球
- `Esc` 退出、`Ctrl+Alt+X` 全局退出
- 只读桌面图标：**不移动、不隐藏、不删除**任何真实图标；退出游戏后桌面保持原样
- 图标图片通过 `PrintWindow` 直接从桌面图标列表窗口渲染，即使图标被终端/浏览器挡住也能正确读取
- 背景通过 Windows 壁纸文件（`TranscodedWallpaper`）渲染，不会把终端/浏览器截进游戏

## 运行

要求：Windows 10 / 11 x64，已安装 .NET 10 SDK 或桌面运行时。

```powershell
cd E:\OtherProject\DesktopBilliards
dotnet run -c Debug
```

或者先构建再运行：

```powershell
dotnet build -c Release
.\bin\Release\net10.0-windows\DesktopBilliards.exe
```

- 建议用**普通用户权限**运行，不要用管理员权限。
- 如果从终端启动，游戏窗口出现后点一下窗口即可操作；任何时候都可以按 `Ctrl+Alt+X` 退出。
- 游戏会出现在**启动时鼠标所在显示器**上；想换显示器，先把鼠标移过去再启动。
- 运行日志：`%TEMP%\DesktopBilliards.log`

## 技术说明

### 1. 为什么图标是圆的

真实桌面图标本身是方形的，直接画一个圆环只能“框住”方形图标，不能把方形边角藏掉。因此这个版本采用**自绘圆形球**：

1. 通过 `PrintWindow` 渲染桌面图标列表 `SysListView32`；
2. 用 `LVM_GETITEMRECT` 读取每个图标的矩形（需要远程内存，因为 `LVM_*` 消息不会跨进程封送指针）；
3. 从渲染结果中裁出图标图片；
4. 中心裁成正方形 → 圆形遮罩 → 玻璃渐变、描边、高光，缓存成 `Bitmap`；
5. 随机抽 15 个图标（不够 15 个用生成球补足）摆到球架上；
6. 游戏窗口覆盖桌面，绘制这些圆形球。真实图标和桌面布局完全不受影响。

### 2. 真实台球摆位与编号

- 球台长轴方向自动判断：横屏时从左到右，竖屏时从上到下；
- 白球放在长轴的 25% 处（头点/head spot）；
- 球架顶点放在长轴的 75% 处（脚点/foot spot），顶点朝白球；
- 5 行等边三角形，相邻球心距为 `2R + 1.5px`，保证球之间刚好不重叠；
- 号码采用 8 球标准摆法：1 号在顶点，8 号在中心，底角是 6 号和 15 号；
- 所有球顶部绘制白色圆形号码牌，显示 1-15；
- 图标池随机打乱后依次放入前 15 个位置；如果不足 15 个，剩余位置使用按号码配色的生成球。

### 3. 背景

优先读取 Windows 当前壁纸文件（Windows Spotlight 的原始文件可能已经不存在，会回退到 `TranscodedWallpaper`），按 `WallpaperStyle` 渲染到工作区大小。这样游戏背景永远是干净壁纸，不会把其他窗口截进去。

如果壁纸渲染失败，才回退到“隐藏图标 → 截屏 → 恢复图标”的方案。

### 4. 渲染性能

- 壁纸、暗角、球台边框、袋口底座一次性渲染到静态 `_board`；
- 每帧只做一次整屏 blit；
- 球贴图 1:1 尺寸，使用 `DrawImageUnscaled`；
- 只有运动中的球和白球绘制柔和阴影；
- 固定步长物理 `1/120s`，界面刷新约 60Hz。

### 5. 连击判定

- 每次非白球落袋：`combo++`；
- 每个落袋球都会把 `lastPocket` 更新为当前袋口；
- 如果一次击球结束时一个球都没进：`combo = 0`；
- `combo >= 2` 时，在 `lastPocket` 上方绘制 `连击 ×N` 标签；
- 新连击出现时清除旧标签，始终显示在**最后进球的袋口**上方。

## 诊断 & 演示

```powershell
# 只读诊断：读取 listview、图标矩形、壁纸渲染、PrintWindow 结果
.\DesktopBilliards.exe --probe
# 输出 probe.txt / listview.png 到 exe 所在目录

# 演示模式：真实开球 → 等 15 颗球散落 → 依次打进 3 颗球
# 会保存球架截图、结算截图，并把散落球局的过程帧写到
# %TEMP%\DesktopBilliards-frames（供录制 2/3 连杆 GIF）
.\DesktopBilliards.exe --demo

# 演示 + 强制只用 5 个图标，其余 10 个用彩色编号球补足
.\DesktopBilliards.exe --demo --fill
```

`--probe` 不会显示游戏窗口；`--demo` 会忽略鼠标输入，只用于验证球架、圆形图标、补足球、开球散落、球杆拉回/出杆、进球特效和 ×2 / ×3 连击。`--fill` 也可以单独用于普通游戏，用来测试“图标不足 15 个”的情况。

## 已知限制 / 下一步

- 游戏期间看到的是“壁纸 + 自绘图标”的游戏视图，桌面/其他窗口被游戏层覆盖，退出后立即恢复；不是实时可交互的桌面。
- 每局只使用随机抽出的 15 个图标，其余桌面图标不参与游戏。
- 游戏内不能双击图标启动程序；这是“游戏模式”的取舍。
- 当前只处理鼠标所在显示器的图标，多显示器可作为后续扩展。
- 4K/高刷下 GDI+ 可能掉帧，后续可换 SkiaSharp、Direct2D 或 DirectComposition。
- 目前无音效；音效对台球手感提升很大，建议下一步加入。
- 可继续增加：最佳成绩、皮肤、袋口网络、幻境模式（全自绘 3D 球体）等。
